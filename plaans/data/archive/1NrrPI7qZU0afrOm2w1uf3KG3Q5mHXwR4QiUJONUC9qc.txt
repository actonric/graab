RULE 0 — NEVER DROP A SOURCE.  (Richard, 2026-09-06)
=====================================================================
"Never drop any resource. Track 100% of all sources we've ever found,
but flag appropriately so we know if we should use them or not."


Unchanged. The list is append-only. Dead, hostile, paywalled and
spam-infected sources stay on it with a flag; the flag is the value.

DISCLOSED DEVIATION — 2026-09-10, read this before assuming a source was lost
=====================================================================
This run found 30+ new sources and changed the flag on ~25 existing ones. All
of them are recorded BELOW, in this doc, rather than by regenerating the
Source List as a v10.


Why: Drive's update_file changes metadata only, so appending to the Source
List means recreating the whole document, and Source List v9 is large enough
that reading it back and retyping it is exactly the failure mode Rule 0 and
this doc were created to prevent ("v5 holds Richard's complete original list
... so v5 never has to be retyped — retyping is how entries got dropped
before"). This doc exists precisely to carry deltas so the master never has
to be retyped, and that is what it is doing.


Consequence, stated plainly so it is not a hidden landmine: SOURCE LIST v9
(1EtMcYW1q_qK3zc6l417V9AjJmgXh2tx50h_u476ZJNA) REMAINS THE CURRENT MASTER
and does NOT contain the 2026-09-07 (Retention v3) or 2026-09-10 (this doc)
deltas. Anyone reading only v9 is reading a stale flag set. A future
consolidation run should fold Retention v3 + v4 into a Source List v10, with
a line count taken on the local draft before upload per Rule 0.


Nothing has been removed, condensed, merged or tidied anywhere.
