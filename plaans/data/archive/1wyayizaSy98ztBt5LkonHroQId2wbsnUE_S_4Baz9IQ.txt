=====================================================================
When Richard asks to add something ad hoc — a photo of a flier, a forwarded
invite, "put this on my calendar" — create it on BOTH the SF Events catalog AND
his personal calendar (richam84@gmail.com).
  - Same title, emoji, description, footer on both.
  - SF Events copy: AVAILABILITY_FREE as usual.
  - Personal copy: AVAILABILITY_BUSY — he actually intends to go.
  - Log BOTH event IDs in TRACKED, marked per calendar, so reconciliation never
    reads the personal copy as a deletion. (Three false positives arose exactly
    this way on 2026-09-07.)
Applies only to adds Richard requests directly. Sweep finds still go to SF Events
alone; school/childcare and action items still go to personal alone.
