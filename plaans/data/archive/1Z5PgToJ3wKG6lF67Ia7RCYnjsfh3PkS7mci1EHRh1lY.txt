RULE 0 — NEVER DROP A SOURCE.  (Richard, 2026-09-06)
=====================================================================
"Never drop any resource. Track 100% of all sources we've ever found,
but flag appropriately so we know if we should use them or not."


Operational meaning:
1. The source list is APPEND-ONLY. Nothing is ever deleted, condensed,
   summarised, merged, or "cleaned up." Not even dead links. Not even
   duplicates — mark the duplicate, keep both lines.
2. A source that turns out to be useless, dead, hostile, paywalled, or
   spam-infected gets a FLAG, not a deletion. The flag is the value:
   it stops us re-checking it next time.
3. Every new source found in any session is appended the same day it is
   found, before the session ends — even if it produced zero events.
4. When the list is regenerated (Drive update_file cannot change content,
   so a new doc must be created), the old doc is RENAMED "superseded",
   never trashed, and the new doc must contain every line of the old one.
   Count the lines before and after. If the count went down, stop.
5. If a list is ever shortened for readability, say so out loud in chat
   before doing it. Do not make that call silently.

=====================================================================
FLAG VOCABULARY — every source carries exactly one USE flag
=====================================================================
[MINED]       Worked. Produced events. Re-check each run.
[PARTIAL]     Worked but not exhausted — known events still unharvested.
[UNTOUCHED]   On the list, never actually opened. Highest-value backlog.
[DRY]         Opened, worked fine, produced nothing relevant to Richard.
              Re-check only seasonally.
[BLOCKED]     Tool/policy refuses it. Not a judgment on the source.
              Sub-reason required: robots / policy / 403 / JS-only / login.
[PAYWALL]     Reachable but costs money or membership to see the calendar.
[COMPROMISED] Serving malware/spam. Do not open. Route around it.
[DEAD]        URL gone or org defunct. Keep the line as a tombstone.
[LEGACY]      Historically useful, no longer publishing. Archive value only.
[NO-URL]      Named by Richard or by a thread, no verified link yet.
[ASK-RICHARD] Only reachable through Richard (private groups, SMS lists,
              logins, physical boards).


Plus an optional QUALITY tier Richard already assigned: A / B / C / Legacy.
Flags describe reachability. Tiers describe worth. Both are kept.
