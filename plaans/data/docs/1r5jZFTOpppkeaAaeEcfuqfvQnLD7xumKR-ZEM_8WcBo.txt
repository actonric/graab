HOW THIS DOCUMENT WAS BUILT, AND THE TOOL BUG YOU MUST KNOW ABOUT
---------------------------------------------------------------------
Built 2026-09-10/11 by concatenating every live delta doc in this family, in
chronological order, verbatim. Nothing was condensed, deduplicated, reordered,
summarised or "fixed". The only transformation applied was CRLF -> LF.


*** DO NOT USE read_file_content ON THESE DOCS. IT SILENTLY TRUNCATES. ***
The first attempt at this merge used Google Drive's `read_file_content` and 9 of
17 manifest docs came back CUT OFF MID-SENTENCE with no error and no marker. It
is not a size limit: Manifest v11, which is under 4KB, was cut mid-word. That
tool also mangles the text -- it returns a reflowed "natural language
representation" with escaping artifacts (\=====, \[Est.\], \#\#) and
corrupts emoji.


USE `download_file_content` WITH exportMimeType="text/plain" AND BASE64-DECODE
IT. That returns the complete, byte-accurate document. Every read that built
this file was done that way and every one was tail-checked for a natural ending.


Implication worth sitting with: any previous run of this skill that read its own
working docs with read_file_content may have been acting on a partial file
without knowing it. That is a candidate explanation for things this skill has
"forgotten" between runs.
