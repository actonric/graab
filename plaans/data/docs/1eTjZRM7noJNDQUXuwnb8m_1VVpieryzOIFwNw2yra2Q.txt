NEW RULE, AND IT IS THE MOST TRANSFERABLE THING THIS RUN FOUND
================================================================================


  A [DRY] FLAG ON AN INSTAGRAM ACCOUNT SAYS NOTHING ABOUT THE OPERATOR'S OWN
  WEBSITE. BEFORE TRUSTING [DRY], CHECK WHETHER THE OPERATOR HAS AN /events PATH.


Evidence, from this run alone:


  @lowerhaightlocal was flagged [DRY] on 09-10 and again on 09-11, with a
  careful and CORRECT structural explanation: it is a print-only neighbourhood
  newspaper whose Instagram carries monthly issue highlights, not listings. Two
  runs concluded the account "will never yield".
  lowerhaightlocal.com/events carries roughly 45 dated neighbourhood events with
  times and venues, plus a public calendar subscription link. It is the richest
  neighbourhood-scale source yet found for Richard's actual radius, and it was
  one click from a page a previous run had already decided not to bother with.


  @shotwellsbar was flagged [DRY]. Its website confirmed the flag — and did so
  DEFINITIVELY, in a way the account never could, by having no events section at
  all. So the check also pays when the answer is no: it upgrades a soft [DRY]
  into a hard structural one and stops future runs re-checking.


  @barebottle was flagged [DRY] on 09-11 because "recent own-account posts did
  not lazy-load". This run the same account's top post was a complete, dated,
  ticketed event announcement. THAT FLAG WAS A LOADING ARTEFACT.


Three accounts, three different lessons, one rule. This generalises the
existing "bio link beats feed" technique (v9, five-for-five) into something
stronger: THE OPERATOR'S DOMAIN IS THE SOURCE. The Instagram account is one
window onto it, the bio link is another, and both can be dark while the
operator's own /events page is fully lit.


COROLLARY, from v9 and reconfirmed: once on the operator's domain, look for the
full calendar path before reading whatever the bio handed you. thefaight.com
/links shows one week; /events shows four months.


SECOND COROLLARY, NEW: when reading an Instagram grid, read the ALT TEXT of
every image rather than the first few by position. Instagram's generated alt
carries the full caption for posts that have one, so searching those strings for
a keyword is far cheaper than opening permalinks — and it found the Oktoberfest
announcement at grid position two after a position-indexed read had missed it.
